MACE Scratch Test Connector (Chrome extension)

Install:
1. Extract this ZIP into a folder.
2. In Chrome, open chrome://extensions
3. Turn on Developer mode.
4. Choose "Load unpacked".
5. Select the extracted folder named mace_scratch_chrome_extension.
6. Open one of YOUR projects at https://scratch.mit.edu/projects/PROJECT_ID/editor/
7. Refresh the Scratch editor page once after installing.
8. Click the Extensions puzzle icon, then pin/open "MACE Scratch Test Connector".

Use:
- Click Refresh variables.
- Select one of the variables shown.
- Enter a number.
- Use Set value, Add value, or Set to 0.

Notes:
- This connector only runs on Scratch project editor pages.
- It works with variables exposed by the current Scratch editor runtime.
- It cannot modify a project permanently in the cloud; save your project normally in Scratch if you want to keep code/project edits. Runtime variable changes may reset on reload.
- If the editor internals change, the connector may need updating.
